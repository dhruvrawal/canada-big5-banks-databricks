# Canada Big 5 Banks – Retail Banking Analytics on Databricks

Analytics project covering RBC, TD, Scotiabank (BNS), BMO and CIBC, built with **PySpark, Spark SQL, Delta Lake and MLlib** on Databricks.

> **Data disclosure:** Real customer data from these banks is not public. All CSVs here are **synthetic**, generated by `scripts/generate_data.py` (seed 42). Bank names are used only as labels. Differences *between banks* are mostly random noise by design; the realistic relationships are inside the data (credit score → default, student → churn, online/large amounts → fraud). Always describe this as a "synthetic dataset" on your resume and LinkedIn.

## Data (`/data`)
| File | Rows | Contents |
|---|---|---|
| banks.csv | 5 | Bank id, name, head office |
| branches.csv | 160 | 32 branches per bank across 10 provinces |
| customers.csv | 20,000 | Age, province, segment, income, credit score, primary bank, churn flag |
| accounts.csv | 40,064 | Chequing, savings, credit card, TFSA, RRSP + balances |
| transactions.csv | 300,000 | Jan 2024 – Dec 2025, category, channel, CAD amount, fraud flag |
| loans.csv | 9,000 | Mortgage, auto, personal, LOC, rate, term, default flag |

## How to run on Databricks (free Community/Free Edition works)
1. Catalog → create a Volume (e.g. `main.default.big5`) and upload the 6 CSVs from `data/`.
2. Workspace → Import → upload `notebooks/Canada_Big5_Banks_Analysis.py` (it imports as a notebook).
3. Edit `BASE` in cell 2 to your Volume path, attach to compute, **Run all**.
4. Screenshot the `display()` charts and build a Databricks SQL dashboard from the `big5_gold_bank_scorecard` table for your portfolio.

## What the notebook does
1. Bronze → Silver Delta tables with dedupe and data-quality filters
2. Customer and deposit share by bank
3. Spend, transaction volume, month-over-month growth (window functions)
4. Fraud rate by bank, category and channel
5. Loan book and default rate by bank, loan type and credit band
6. Provincial footprint and churn by segment
7. Random Forest loan-default model (MLlib, AUC on 20% holdout)
8. Gold scorecard table for BI tools

## Sample results (verified with pandas replica: `scripts/local_results.py` → `/results`)
- Default rate by credit score: **12.0%** for <600 vs ~2–3% for 600+ (strongest risk driver)
- Personal loans default most (**4.9%**) vs ~2.8% for mortgages
- Online shopping has the highest fraud rate (**0.77%** vs ~0.3% average)
- Students churn most (**13.3%** vs ~8% others)

- Random Forest loan-default model (Spark MLlib, 80/20 split, seed 42): **AUC = 0.665**; credit score is the top feature (importance 0.26), followed by annual income, age and interest rate. Modest by design, since the synthetic default flag is mostly noise on top of a few rules.

All figures come from a local PySpark run (`notebooks/Canada_Big5_Banks_Local.py`; full output in `results/spark_run_output.txt`). A Databricks run on the same CSVs should match; the model AUC may differ slightly with the Spark version.
